# Image Asset Guide

To use your own images in FuelMails, place your files in this directory (`public/images/`) following the structure below. The app is already configured to look for these filenames.

## Core Assets
- `logo.png` -> Your company logo

## Team Photos
- `anish.jpg` -> Photo of Anish Pantha
- `bishalya.jpg` -> Photo of Bishalya Gautam

## Blog Thumbnails
Place these in `public/images/blog/`:
- `blog-1.png`
- `blog-2.png`
- `blog-3.png`

## Email Templates
Place these in `public/images/templates/`:
- `template-1.png`
- `template-2.png`
- `template-3.png`
- `template-4.png`
- `template-5.png`
- `template-6.png`

## Case Studies
Place these in `public/images/case-studies/`:
- `banner-1.png` (Banner for GigaMart)
- `email-1.png` (Email example for GigaMart)
- `banner-2.png` (Banner for Innovate Inc.)
- `email-2.png` (Email example for Innovate Inc.)

> **Note:** If your file names or formats (e.g., .jpg vs .png) are different, you can update the paths in `src/app/lib/placeholder-images.json`.
