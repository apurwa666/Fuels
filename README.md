
# FuelMails - Project Download & Local Setup

To download this entire project and run it locally, follow these steps:

### 1. Package the project
Open the terminal at the bottom of the screen (Ctrl + ` or Cmd + `) and type:
```bash
bash download-project.sh
```

### 2. Download the Archive
Once the command finishes, a file named **`project.tar.gz`** will appear in the sidebar on the left. **Right-click** that file and select **Download**.

### 3. Local Setup
1. Extract the downloaded `.tar.gz` file on your computer.
2. Follow the instructions in `DEVELOPMENT.md` to install dependencies and run the app.

---

### Key Directories
- `public/images/`: Place your local images here.
- `src/app/lib/placeholder-images.json`: Map your image filenames to the code here.
